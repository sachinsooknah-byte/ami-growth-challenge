## Important while testing
- **Data is stored in each person's own browser.** Testers cannot see each other's entries or votes yet. Test the flows on your own device, with the sample data.
- **Sign-in is a demo.** A board member's password is created on first sign-in in that browser only. This is not real security. Do not enter real guest details until the shared-database version with real sign-in is in place.
- Keep the same Netlify address, or browsers will start with empty data.
